-----------------------------------------------------------

6. ESTRUCTURA DEL PROYECTO
-----------------------------------------------------------
   app/                    → Páginas y API routes
     api/                  → Endpoints REST
       servicios/          → CRUD Servicios
       cotizaciones/       → CRUD Cotizaciones
       vehiculos/          → CRUD Vehículos
       conductores/        → CRUD Conductores
       login/              → Autenticación
       facturacion/        → Facturación
       mantenimiento/      → Mantenimiento
       documentos/         → Documentos
       contabilidad/       → Contabilidad
       setup/              → Setup inicial (seed)
     login/                → Página de login
     servicios/            → Página de servicios con calendario
     cotizaciones/         → Página de cotizaciones
     vehiculos/            → Gestión de vehículos
     page.tsx              → Dashboard principal
   components/             → Componentes React
     ServiceCalendar.tsx   → Calendario de servicios
     ServiceModal.tsx      → Modal de servicios
     QuotationTemplate.tsx → Template PDF de cotización
     QuotationModal.tsx    → Modal de cotizaciones
   prisma/                 → Schema y migraciones BD
   lib/prisma.ts           → Cliente Prisma singleton

7. COMANDOS ÚTILES
